Installation

Place opencode.json in your OpenCode config directory:

OSPath
Linux~/.config/opencode/opencode.json
MacOS~/.config/opencode/opencode.json
Windows%APPDATA%\opencode\opencode.json

Quick Start

git clone https://github.com/<your-user>/opencode-multi-agent.git
cp opencode-multi-agent/opencode.json ~/.config/opencode/opencode.json
opencode
# Use planning mode only
opencode --agent plan
